# CyberLogitec OPUS (Allegro / LMS) — Internal Wiki

A single-file, self-contained HTML reference for the **CyberLogitec OPUS Container** system used by our shipping operations. Built for Cost Controllers and Finance users who need to understand what every screen does, what to enter in each field, and how accrual flows end-to-end.

## What's inside

- **46 articles** covering all five core modules:
  - **COA** — Cost Accrual (Cost Table, U/C-CM, U/C-OP, Estimated Cost, Allocation, Reports, Simulation)
  - **JOO** — Joint Operation (Setup, Settlement, Monthly Clearance, CSR, Reports)
  - **PSO** — Port Service Order (Tariff, Simulation, Planned, Invoice, Canal)
  - **TES** — Terminal Service (MR, Off-Dock, Storage, AGMT)
  - **TRS** — Transportation Service (AGMT, S/O, W/O, Invoice, USA Rail)
- **Interactive accrual flow diagram** — clickable SVG mapping the 7-phase cycle from master data to P&L reporting
- **Workflow guides** — Cost Accrual, Invoice Audit, CSR → ERP, Month-End Closing
- **Glossary, Codes reference, FAQ, Tips**
- Sidebar search and anchor-based navigation (no server required)

## How to use

Just open `CyberLogitec_OPUS_Wiki.html` (or `index.html`) in any modern browser. Both files are identical — the `index.html` copy exists so GitHub Pages can serve it as a website if enabled later.

- No build step, no dependencies, no internet needed to view
- Client-side search: type in the sidebar search box
- Click any coloured box in the accrual flow diagram to jump to that screen's article

## Source material

Built from the five official CyberLogitec user manuals (COA, JOO, PSO, TES, TRS) and the COA Concept paper, combined with operational knowledge of how these screens are used day-to-day in cost controlling.
